04

Captura automatizada de publicações em redes sociais

API própria, proxies, sessões, ScreenshotAPI e Amazon S3.

+

O desafio

Automatizar capturas de redes sociais com estabilidade, controle de autenticação, tratamento de bloqueios e armazenamento centralizado.

A solução criada

Uma API personalizada consulta os registros no banco, encaminha a solicitação por uma infraestrutura de proxies e gerenciamento de cookies e sessões, envia o pedido à ScreenshotAPI, recebe a imagem, salva no Amazon S3 e retorna o resultado ao sistema.

Fluxo

  1. Banco de dados identifica o conteúdo
  2. API prepara o processamento
  3. Proxy e sessão autenticada são aplicados
  4. A captura é gerada
  5. A imagem é salva no S3
  6. O sistema recebe o retorno
