# Páginas SEO — Santana Tech

Este pacote contém as oito páginas internas solicitadas.

## Implantação
Copie cada pasta para a raiz pública do site e copie `css/solution-page.css` para a pasta CSS. As páginas esperam que estes arquivos já existam na raiz:

- `/css/style.css`
- `/css/reputation.css`
- `/js/script.js`
- `/assets/logo.png`
- `/assets/favicon.png`
- `/assets/whatsapp.png`
- `/assets/og-santana-tech-reputacao.jpg`

## Ajustes obrigatórios
Substitua `https://www.seudominio.com.br` pelo domínio real em todos os HTMLs, no sitemap e no robots.txt. Revise telefone, e-mail e endereço.

## Observação sobre formulário
O formulário continua usando `mailto:` para manter compatibilidade com a home enviada. Para captação profissional, substitua por um endpoint real (AWS Lambda + SES, API própria ou serviço de formulário), com página de sucesso e registro de conversão.
